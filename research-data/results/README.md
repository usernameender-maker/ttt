# Benchmark result retention

This directory is reserved for benchmark artifacts generated by the deterministic validation pipeline.

- Keep only validated JSONL result logs here.
- Each artifact should be attributable to a scenario catalog, a deterministic seed set, and a specific revisions/commit.
- Use `scripts/verify_all.sh` or the benchmark runner to write results to this directory.
- Do not commit temporary files, debug logs, or unvalidated output.

Valid retained files should have the form:

- `research-data/results/*.jsonl`
- `research-data/results/*.md` for short summaries
