# Communication research prototype status

The communication subpackage currently starts with a classical shortened
Hamming `[5,2,3]` code and binary dual-orientation transformations. This is a
staged research prototype, not a validated communications system.

## Implemented first milestone

- Four `[5,2,3]` codewords, generated by `(a,b) -> (a,b,a xor b,a,b)`.
- Exhaustive minimum-distance verification and syndrome decoding, with all
  single-bit errors corrected.
- A two-bit error is detectable when its syndrome is not a single-bit column;
  some two-bit patterns alias a single-error syndrome and are not guaranteed
  detectable or correctable. No stronger claim is made.
- Positive orientation is identity; negative orientation is bitwise complement.
  Complement and coordinate reversal independently preserve Hamming distance.
  To decode a transformed codeword using the original parity-check matrix,
  first align it back, or explicitly transform the matrix.

No Morse framing, stochastic channel, statistical benchmark, Walsh model, or
quantum simulation is implemented in this milestone. Those are future stages,
not measured results. All code uses the Python standard library.

Run the focused tests with:

```sh
python -m unittest discover -s tests/communication -v
```
